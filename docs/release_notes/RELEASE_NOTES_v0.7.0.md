**Release Date**: 2026-01-27

## Overview

v0.7.0 introduces **Cost Tracking & Token Usage Monitoring** with **LiteLLM Multi-Model Support**. This release enables comprehensive cost analysis across multiple LLM providers (OpenAI, Anthropic) with automatic token tracking, cost calculation, and detailed analytics APIs.

---

## 🎯 Key Features

### 1. Token Usage Tracking

Automatically tracks token usage for every LLM request:
- **Input tokens**: Prompt tokens sent to the model
- **Output tokens**: Response tokens generated by the model
- **Total tokens**: Combined input + output
- **Cached tokens**: Prompt cache hits (reduces cost)
- **Reasoning tokens**: Extended thinking tokens (GPT-5 specific)

All token information is:
- Captured from LLM API responses
- Stored in database (`llm_logs` table)
- Returned in `/chat` API response
- Available for cost calculation

### 2. Cost Calculation & Tracking

Accurate USD cost calculation based on token usage:
- **Model-specific pricing**: Each model has configured input/output prices per 1M tokens
- **Cached token discounts**: Proper accounting for prompt caching
- **DECIMAL precision**: Uses DECIMAL(10, 6) to avoid floating-point errors
- **Database storage**: Costs saved with each log (cost_input_usd, cost_output_usd, cost_total_usd)

### 3. Cost Analysis APIs

Four new API endpoints for cost analysis:

#### `GET /cost/summary`
Comprehensive cost summary with filters:
```bash
curl "http://localhost:18000/cost/summary?start_date=2026-01-01&end_date=2026-01-31"
```

**Response**:
```json
{
  "total_cost_usd": "123.45",
  "total_requests": 10000,
  "total_input_tokens": 5000000,
  "total_output_tokens": 2000000,
  "breakdown_by_model": [
    {
      "model_version": "gpt-5-mini",
      "cost_usd": "80.00",
      "requests": 8000,
      "avg_cost_per_request": "0.01"
    }
  ],
  "breakdown_by_user": [...]
}
```

**Query Parameters**:
- `user_id`: Filter by specific user
- `model_version`: Filter by model
- `start_date`: Start date (YYYY-MM-DD)
- `end_date`: End date (YYYY-MM-DD)

#### `GET /cost/trends`
Time-series cost analysis:
```bash
curl "http://localhost:18000/cost/trends?granularity=hour&hours=24"
```

**Response**:
```json
{
  "data": [
    {
      "timestamp": "2026-01-20 10:00:00",
      "cost_usd": "12.34",
      "requests": 500,
      "input_tokens": 250000,
      "output_tokens": 100000
    }
  ]
}
```

**Query Parameters**:
- `granularity`: `hour` | `day` | `week` | `month`
- `hours`: Look-back hours (max 720 = 30 days)
- `days`: Look-back days (max 90)

#### `GET /cost/models`
Model cost efficiency analysis:
```bash
curl "http://localhost:18000/cost/models?days=7"
```

**Response**:
```json
{
  "models": [
    {
      "model_version": "gpt-5-mini",
      "avg_cost_per_request": "0.01",
      "avg_quality_score": 4.2,
      "cost_per_quality_point": "0.0024",
      "recommendation": "최고 가성비 모델"
    }
  ]
}
```

Includes:
- Average cost per request
- Average quality score (from evaluations)
- Cost per quality point (cost efficiency metric)
- Automatic recommendation based on efficiency

#### `GET /models/pricing`
Query configured model pricing:
```bash
curl "http://localhost:18000/models/pricing?provider=openai"
```

**Response**:
```json
{
  "models": [
    {
      "model_name": "gpt-5-mini",
      "provider": "openai",
      "price_input_per_1m": "0.2500",
      "price_output_per_1m": "2.0000",
      "price_cached_per_1m": "0.0000",
      "context_window": 400000,
      "is_active": true,
      "description": "Cost-efficient GPT-5 variant..."
    }
  ]
}
```

**Query Parameters**:
- `provider`: Filter by provider (openai, anthropic)
- `is_active`: Filter by active status

### 4. LiteLLM Multi-Model Support

Replaced OpenAI SDK with **LiteLLM** for unified multi-provider support:

**Benefits**:
- **100+ models**: OpenAI, Anthropic, Google, Cohere, Azure, AWS Bedrock, etc.
- **Unified API**: Single interface for all providers
- **Automatic retries**: Built-in error handling
- **Easy switching**: Change models without code changes

**Usage** (transparent to API clients):
```python
# Client just specifies model name
response = requests.post("/chat", json={
    "prompt": "Hello",
    "model_version": "claude-sonnet-4"  # Works with any supported model
})
```

**Fallback Support**:
- Automatic fallback to alternative models on failure
- Configured via `FALLBACK_MODELS` environment variable
- Default: `["gpt-4o-mini", "claude-haiku-4"]`
- Example: If primary model fails, automatically tries fallback models in order

## 📊 Database Changes

### New Fields in `llm_logs` Table

```sql
ALTER TABLE llm_logs
ADD COLUMN IF NOT EXISTS input_tokens INTEGER,
ADD COLUMN IF NOT EXISTS output_tokens INTEGER,
ADD COLUMN IF NOT EXISTS total_tokens INTEGER,
ADD COLUMN IF NOT EXISTS cached_tokens INTEGER DEFAULT 0,
ADD COLUMN IF NOT EXISTS reasoning_tokens INTEGER DEFAULT 0,
ADD COLUMN IF NOT EXISTS cost_input_usd DECIMAL(10, 6),
ADD COLUMN IF NOT EXISTS cost_output_usd DECIMAL(10, 6),
ADD COLUMN IF NOT EXISTS cost_total_usd DECIMAL(10, 6);
```

### New Table: `llm_model_pricing`

```sql
CREATE TABLE IF NOT EXISTS llm_model_pricing (
    id SERIAL PRIMARY KEY,
    model_name VARCHAR(128) UNIQUE NOT NULL,
    provider VARCHAR(64) NOT NULL,
    price_input_per_1m DECIMAL(10, 4) NOT NULL,
    price_output_per_1m DECIMAL(10, 4) NOT NULL,
    price_cached_per_1m DECIMAL(10, 4) DEFAULT 0,
    context_window INTEGER,
    max_output_tokens INTEGER,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    description TEXT,
    tags TEXT[]
);
```

**Migration**: Run `scripts/migrate_v0.7.0.sql` to apply schema changes.

## 📝 API Changes

### `/chat` Endpoint Response Extended

**Before v0.7.0**:
```json
{
  "response": "Hello!",
  "model_version": "gpt-5-mini",
  "latency_ms": 1234.5
}
```

**v0.7.0+**:
```json
{
  "response": "Hello!",
  "model_version": "gpt-5-mini",
  "latency_ms": 1234.5,
  "usage": {                    // NEW
    "input_tokens": 10,
    "output_tokens": 20,
    "total_tokens": 30,
    "cached_tokens": 0,
    "reasoning_tokens": 0
  },
  "cost": {                     // NEW
    "input_usd": "0.000002",
    "output_usd": "0.000040",
    "total_usd": "0.000042"
  }
}
```

**Backwards Compatibility**: ✅ Fully compatible
- New fields (`usage`, `cost`) are optional
- Existing clients continue to work without changes
- Fields are `null` if cost calculation fails
